# 🤖 Jarvis Chatbot

A Python-based personal AI voice assistant inspired by J.A.R.V.I.S. from Iron Man. This project aims to make everyday computer interactions easier through voice commands and automation.

## ✨ Features

- 🎙️ Voice Recognition – Recognizes user voice commands.
- 🔊 Text-to-Speech – Responds with voice output.
- 💻 Desktop Automation – Performs basic computer tasks.
- 🗣️ Voice Interaction – Communicates with the user through speech.
- ⚡ Wake Word – Responds to the Jarvis activation command (if configured).

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- PyAutoGUI

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/SiddhantShukla12x/Jarvis-chatbot.git
```

### 2. Navigate to the project folder

```bash
cd Jarvis-chatbot
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

Windows PowerShell:

```bash
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the project

```bash
python main.py
```
